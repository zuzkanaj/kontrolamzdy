# KontrolaMzdy v2

Testovacia webová aplikácia pre kontrolu dochádzky a výplatnej pásky na jednom oddelení FNsP Prešov.

## Zmena vo verzii v2

Po OCR sa najprv zobrazia všetky rozpoznané hodnoty. Chýbajúce hodnoty sú označené červenou a používateľ ich musí doplniť. Až následne sa spustí kontrola mzdy.
